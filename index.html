01 / BEFORE YOU START

Welcome to your project guide.

This project uses applicant and loan details to estimate a risk category with a trained Random Forest machine-learning model.

⌁

Enter details

Provide eight numeric values about the applicant and requested loan.

◎

Model analysis

The frontend sends the values to the Flask API, which runs the trained model.

✧

View prediction

The application displays LOW RISK or HIGH RISK and may show a high-risk probability.

RememberThis is an academic demonstration. A prediction is not a loan approval, rejection, or professional financial assessment.
